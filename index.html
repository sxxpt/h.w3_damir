What are HTML and CSS for

HTML

Markup language. Responsible for the structure and content of the page: headings, text, images, links, lists.

CSS

Style language. Responsible for the appearance: colors, fonts, margins, layout.

HTML is the skeleton of a house, CSS is the finishing and design.

HTML Tags

Tag Purpose Example (in code)
<h1> Top-level heading <h1>Heading</h1>
<p> Text paragraph <p>Text</p>
<a> Link <a href="link">How a link looks</a>
<img> Image <img src="path_to_image.jpg" alt="image description">
<div> Universal block container for grouping elements <div>...</div>
<ul> Unordered (bulleted) list <ul>...</ul>
<li> List item <li>List item</li>

Paired and Single Tags

Type Tags Explanation
Paired (Double) <h1> <p> <a> <div> <ul> <li> Has an opening and a closing tag, content goes between them
Single <img> No closing tag, data is provided via src and alt attributes

About <div>

What is it for

A container that doesn't render visually on its own but groups elements for common styling.

How to use

Wrap related elements in a single <div>.

<div>
  <h1>My Page</h1>
  <p>Here is my first text.</p>
</div>

About <ul> and <li>

<ul>: container for an unordered list.

<li>: a single item, used only inside a <ul>.

<ul>
  <li>First item</li>
  <li>Second item</li>
  <li>Third item</li>
</ul>
  • First item
  • Second item
  • Third item

A bit about CSS

1. CSS Rule

Consists of a selector, property, and value:

p {
  color: blue;
  font-size: 18px;
}

2. Property Table

Property What it does Example
color Text color color: red;
background-color Background color background-color: #222;
padding Inner spacing (padding) padding: 20px;

3. "Before & After" Demo

Demonstration block without styles. Same text, but looks different.
Demonstration block with styles. Same text, but looks different.

4. Three ways to include CSS

  • style="" attribute (inline styles)
  • <style> tag inside <head>
  • External style.css file (recommended)
